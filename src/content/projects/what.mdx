## 01 / Problem

Learning a language with music works because songs are memorable — but turning a
song into a lesson is manual and slow. You have to find the audio, separate the
vocals from the instrumental, get accurate lyrics, align them in time with the
audio, and collect the vocabulary you actually want to review.

## 02 / Architecture

The project is a full-stack app built around a data pipeline:

```text
search → download (yt-dlp) → voice separation → Whisper transcription
        → Genius lyric sync → React frontend → Anki export
```

- **Backend**: FastAPI (async) + SQLAlchemy (async) + SQLite. Modules: `api`
  (routes), `core` (downloader, transcriber, aligner, lyrics, exporter),
  `config` (central YAML) and `database`.
- **Frontend**: React 19, TypeScript, Vite, Tailwind 4, TanStack Query,
  React Router, Framer Motion.
- **Launcher**: `what-question` starts backend and frontend together and stops
  both on Ctrl+C. Ports are configurable via environment variables.

## 03 / Implementation

- **Download**: audio fetched with `yt-dlp`, the same tool used across three of
  my projects.
- **Transcription**: `faster-whisper` (large-v3) transcribes the separated
  vocals; the Whisper model and API tokens live in a central YAML config.
- **Alignment**: transcriptions are synchronized with official Genius lyrics so
  text follows the audio in time.
- **Frontend**: the lesson UI renders the synced transcription with
  translations, backed by TanStack Query for data fetching and Framer Motion
  for transitions.

## 04 / Engineering Decisions

- **Async everywhere in the backend** — transcription and network I/O are the
  slow parts; async keeps the API responsive.
- **Single launcher over two processes** — one command for the user, both
  services managed together; ports configurable for coexistence with other dev
  servers.
- **Central YAML config** — model choice, tokens and paths in one place instead
  of scattered env vars.

## 05 / Testing

The repo ships a Python suite with pytest (asyncio) alongside the implementation
and frontend work is verified with Playwright in other repos in the portfolio.

## 06 / Results

A working learning tool: search a song, get a synced, translatable transcript
and export the vocabulary to Anki. It is my most complete full-stack project —
React 19 + TypeScript frontend, async FastAPI backend, local AI (Whisper) and a
real product loop.

## 07 / Lessons Learned

- Whisper transcription quality is strongly affected by voice separation; doing
  both is worth the complexity.
- Keeping configuration centralized makes local-AI projects much easier to run
  on different machines.
- A project is only finished when it is documented and runnable with one command.
